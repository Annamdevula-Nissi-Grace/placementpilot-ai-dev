# 🚀 PlacementPilot AI

### AI-Powered Placement & Career Preparation Platform

PlacementPilot AI is a production-style **AI-powered career preparation platform** designed to help students prepare for software engineering placements through personalized learning, skill-gap analysis, DSA practice, resume analysis, mock interviews, company preparation, job tracking, analytics, and AI career coaching.

🔗 **Live Demo:** https://placementpilot-ai-dev.vercel.app/

💻 **GitHub Repository:** https://github.com/Annamdevula-Nissi-Grace/placementpilot-ai-dev

# ✨ Features

PlacementPilot AI contains a complete multi-screen career preparation experience.

## 📊 Dashboard

The dashboard provides a personalized overview of the student's placement preparation.

Includes:

- Overall preparation progress
- Current skill score
- Weekly activity
- Upcoming tasks
- Learning progress
- Recommended actions
- Placement readiness overview

---

## 👤 Student Profile

Students can manage their professional profile.

Features:

- Personal information
- College information
- Graduation details
- Location
- Career summary
- Technical skills
- Target roles
- Experience
- Profile completeness
- Profile editing

---

## 📄 AI Resume Analyzer

Analyze and improve a resume before applying for jobs.

Features:

- Resume upload interface
- Resume analysis workflow
- Resume score
- Improvement recommendations
- Resume sections
- AI-powered suggestions

---

## 🎯 Skill Gap Analysis

Identify the skills that need improvement for software engineering placements.

Features:

- Overall skill match
- Strong skills
- Priority gaps
- Skill scores
- Priority learning areas
- AI recommendations
- Learning priorities

Example areas include:

- Data Structures & Algorithms
- System Design
- Operating Systems
- Programming
- Backend Development

---

## 🗺️ 30-Day Placement Roadmap

A structured learning roadmap for placement preparation.

Features:

- 30-day preparation plan
- Daily learning tasks
- Progress tracking
- Task completion
- Learning milestones
- AI recommendations

---

## 💻 DSA Practice

Practice Data Structures & Algorithms problems.

Features:

- Problem search
- Topic filtering
- Difficulty filtering
- Problem completion
- Progress tracking
- AI explanations
- Learning recommendations

Supported concepts include:

- Arrays
- Strings
- Linked Lists
- Trees
- Graphs
- Dynamic Programming
- Sorting
- Searching

---

## 🎤 AI Mock Interview

Practice technical interview questions using an interactive interview experience.

Features:

- AI-generated interview questions
- Answer submission
- AI feedback
- Performance evaluation
- Next-question workflow
- Interview progress

The current frontend uses simulated AI feedback and can later be connected to a real AI API.
